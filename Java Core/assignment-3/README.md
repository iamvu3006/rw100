# TestingSystem_Assignment_3

This project organizes Assignment 3 into packages:
- `backend`: Exercise classes, one method per question
- `frontend`: Program classes to demo each exercise
- `entity`: Simple data classes used by exercises

Entry points:
- `src/Program.java` runs Program1..Program6
- `src/Main.java` calls Program

I did not run or compile any code as requested.

Optional run (if you choose to compile locally):

```powershell
javac -encoding UTF-8 -d out (Get-ChildItem -Recurse -Filter *.java | Select-Object -ExpandProperty FullName)
java -cp out Main
```
