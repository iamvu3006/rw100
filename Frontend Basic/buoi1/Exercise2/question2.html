Các bước nộp bài tập qua Git (Ordered List)

  1. Tạo thư mục dự án với tên TestingSystem_Assignment_1
  2. Viết mã nguồn cho các bài tập
  3. Sử dụng lệnh git add . để thêm tệp tin
  4. Sử dụng lệnh git commit -m "Hoàn thành bài tập"
  5. Push code lên kho lưu trữ từ xa (Remote Repository)
